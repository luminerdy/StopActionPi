# StopActionPi hardware parts list

| Part | Quantity per station | Details |
| --- | ---: | --- |
| Raspberry Pi 500 | 1 | Built-in keyboard. **Space** takes a photo. [Raspberry Pi 500](https://www.raspberrypi.com/products/raspberry-pi-500/) |
| USB-C power supply | 1 | Official Raspberry Pi 27 W power supply. [Desktop Kit contents](https://www.raspberrypi.com/products/500-desktop-kit/) |
| microSD card | 1 | The Desktop Kit includes a 32 GB card. [Desktop Kit contents](https://www.raspberrypi.com/products/500-desktop-kit/) |
| HDMI monitor | 1 | Displays the live camera and photo review. A monitor with speakers can play back narration. [Raspberry Pi display and audio documentation](https://www.raspberrypi.com/documentation/computers/keyboard-computers.html) |
| Micro-HDMI-to-HDMI cable | 1 | Connects the Pi to the monitor. [Desktop Kit contents](https://www.raspberrypi.com/products/500-desktop-kit/) |
| Logitech USB webcam | 1 | The **C270** is the tested 720p fixed-focus camera. The **C920** is the planned 1080p autofocus upgrade. Both have built-in microphones. [C270 specs](https://www.logitech.com/content/dam/logitech/en/support/qsg/education-center/logitech-c270-for-education-one-pager.pdf) · [C920 guide](https://www.logitech.com/assets/42685/4/c920-quickstart-guide.pdf) |
| OXENDURE 22-inch webcam suspension arm | 1 | Round-base scissor arm to hold the camera steady. A sturdy 3D-printed webcam holder is another option. |
| 8BitDo Micro Bluetooth gamepad | 1 optional | Planned handheld shutter. Map a button to **Space** in Keyboard Mode. Pairing and capture still need to be tested on the Pi. [8BitDo Keyboard Mode manual](https://manual.8bitdo.com/micro/micro-keyboard-bluetooth.html) · [Button mapping](https://support.8bitdo.com/ultimate/micro.html) |
| USB mouse | 1 optional | Useful for clicking thumbnails and drawing on photos. [Desktop Kit contents](https://www.raspberrypi.com/products/500-desktop-kit/) |
